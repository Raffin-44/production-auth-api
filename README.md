# Production Authentication API

A production-ready authentication API built with Node.js, Express, and TypeScript.

##  Tech Stack

- Node.js
- Express
- TypeScript
- Supabase / Prisma

##  Installation

Clone the repository:

git clone <your-repo-url>

Install dependencies:

npm install

##  Development

Run TypeScript compiler:

npx tsc

(Development scripts will be added later)

##  Project Structure

production-auth-api/
│
├── src/              # Source code
├── dist/             # Compiled JavaScript output
├── node_modules/
├── .gitignore
├── package.json
├── package-lock.json
└── tsconfig.json

Create a `.env` file based on `.env.example` (to be added later).
